Residual-grid `grid_step/ATR` is a price-equivalent conversion from residual standard deviation, not a resting price-grid measurement. Natural-grid levels are actual resting limits. HF prices are adjusted, so level placement is mechanically comparable but not raw-price execution evidence.

Averaging is judged meaningful only when improvement exceeds 0.1 ATR. Counterfactual stop/TP conclusions remain explanatory and require new OOS validation.
